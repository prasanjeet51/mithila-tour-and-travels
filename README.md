# Mithila Tour and Travels — Cab Booking

A booking landing page for Mithila Tour and Travels, a cab service in Muzaffarpur, Bihar.

**Live site:** https://warm-pithivier-b7a79e.netlify.app/

## What it does

- 11 city-pair routes across Bihar, plus airport pickup (Patna, Gaya, Darbhanga)
- Cab types: Mini, Sedan, SUV, Traveller
- Ride Now or Schedule a Ride; One Way, Round Trip, or Local
- Typo-tolerant place search with a Google Maps route preview and distance
- Booking goes straight to WhatsApp — fares are confirmed there, no prices on the site

## Files

- `index.html` — the live site (built from `template.html`)
- `template.html` — source template
- `assets/` — cab photos and route photos
